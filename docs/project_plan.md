## 下一步：Step 2 文献综述

1. 以旧选题稿中的六条文献线索为起点，核对全文和出版信息，完成至少 5–8 篇可信来源的选择。
2. 建立文献矩阵，记录研究问题、地区与年份、分析单位、价格口径、营养和环境指标、方法、结论及对本项目的用途。
3. 比较类别内与类别间分析、不同计价单位和环境指标含义，提炼本项目的问题与指标选择。
4. 形成 2–3 页综述及更新后的研究问题，统一参考文献格式。

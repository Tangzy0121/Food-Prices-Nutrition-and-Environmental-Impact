## Step 3 已完成内容

1. 将本地价格快照定位至上游固定版本并核对 SHA-256；R 导入复现 83,141 条报价、44,789 个候选条码。
2. 完成 500 条码／50 数值请求试取，随后完整枚举四类目录，与历史价格连接，得到 3,002 个可抽样候选；按固定种子 20261102 每类抽取 150 款，共 600 款。
3. 对全部 600 款请求全部计划字段，600 款均取得商品对象，没有未请求项；搜索遗漏已用单商品接口确认补取。
4. 核查规格、多件装、单位、折扣和重复报价，处理两项规格排除，得到 598 款主要比较商品及 1,541 条对应报价；保留原始观察、不同代表价格口径与分年结果。
5. 主营养等级统一为 Nutri-Score 2023，六项冲调状态等级单独保留；568 款具备价格与两种等级，594 款主要比较商品具有 AGRIBALYSE 3.2 碳估算。
6. 完成正式数据说明、字典、覆盖表、规格处理决定、版本表与参考食品映射；通过请求覆盖、主键、连接、物理单位、全部代表价格及来源哈希校验，冻结 `frozen_v1`。

正式获取使用只读 POST 批量搜索，逐请求缓存响应、参数和获取时间。早期试取与 Parquet 试探作为过程材料保留，正式 EDA 使用 `data/processed/frozen_v1/analysis_products.rds`。默认运行入口校验冻结数据，不再发起网络请求。

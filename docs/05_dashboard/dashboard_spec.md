# 同类食品比较仪表板设计草稿

> 本页保留早期消费者导向的 Shiny 草稿。2026-11-13 用户确认的网站研究 dashboard 以[六方向图表方案](research_dashboard.md)为准。

2026-11-05。此为 Step 5 草稿，依据本轮已运行的 EDA，供小组讨论和 Shiny 实现使用。

## 用户与决策

主要用户为比较同类包装食品的消费者。用户选择一个食品类别，在预算和评分条件下找出值得进一步比较的商品，再查看两款商品的具体成分及报价背景。界面说明数据为法国 2024—2025 年历史报价，商品资料获取于 2026-11-02。

## 页面与顺序

```text
类别内概览
  类别选择 → 有效商品数与价格单位 → 价格分布与等级覆盖
       ↓
筛选与发现
  单位价格上限 + 营养等级 + 环境等级 → 联动图与商品表
       ↓
两款商品比较
  两个条码选择 → 单位价格、等级、成分、包装、报价次数和日期
```

| 页面 | 组件 | 用户动作与结果 |
|---|---|---|
| 概览 | 类别选择器、覆盖统计、价格分布 | 选一个类别；价格单位和上限同步变化 |
| 筛选 | 价格上限、营养等级、多选环境等级、缺失显示开关 | 联动散点和商品表，显示筛选后的 n 与总 n |
| 对比 | 两款商品选择器、差异表、报价背景 | 比较成分与等级，核查价格是否只有一条报价 |
| 方法 | 数据来源、指标方向、价格口径、等级说明 | 理解评分和历史价格的含义 |

## 由 EDA 决定的设计

- 四类食品的价格—评分关联不同，类别选择是整个应用的首要条件。
- 饼干和果汁的两项综合分数关联接近零，界面突出具体商品比较，不把价格当作质量标签。
- 黑巧克力价格与糖、饱和脂肪方向相反，对比页同时呈现二者，并保留纤维。
- 营养 A/B 的某些类别样本很少，每张图和表显示有效商品数，未知等级可以单独查看。
- 环境等级完整包含 A+—F，营养等级为 A—E。两项图例与排序分别实现。
- 291 款只有一条常规报价，对比页显示次数与日期，避免价格差异脱离记录背景。
- 碳估算共享参考项，作为方法或参考视图展示；不对每个品牌画出独立实测碳足迹的印象。

## 数据契约

主输入为 `data/processed/step4_v1_1/analysis_products.rds`，598 行。三维比较使用 `joint_grades_price` 对应的 583 行；具体营养数值按视图选择。商品条码按字符保留。价格单位来自 `target_unit`。候选商品对可读取 `outputs/step4/tables/comparison_candidates.csv`。

主筛选使用同一份 reactive 数据；图、表和数量共用它。对比页从同类商品中选两款，允许固定已选商品后调整筛选条件，并清楚提示已选商品是否位于当前筛选结果中。

## 实现边界与验收

Shiny 采用清楚的 UI/server 分离，应用从项目文件本地启动。初版完成类别、价格上限、等级筛选、联动表图和两商品选择；这些交互对应三项用户任务。无需实时 API。

验收时逐项操作：切换 kg/L 类别后单位与预算正确；A+ 和 F 排序正确；不存在的条件组合出现空状态；未知等级开关不改变其他图的分母定义；同一商品不会被同时选为两款；商品数、表格行数与图点数一致；显示日期与报价次数；干净启动可以完成三项用户任务。

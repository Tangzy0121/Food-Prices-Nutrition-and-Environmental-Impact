# 网站研究 Dashboard

2026-11-13。以用户提供并确认的六方向图表表格为设计依据。网站延续已有浅色黑白视觉，少量绿色表达选中状态和具体数据含义。使用事实性标题，通过排版、图例、表头和控件位置组织内容。

## 图形规则

- 箱线图与 R 的 `scale_y_log10()` 一致：先变换价格，再计算 type-7 四分位数与 1.5 IQR 须线。叠加所有商品点，横向抖动固定且不改变价格坐标。
- 营养等级箱线图与环境等级箱线图分别排除缺少对应等级的商品。糖散点图只排除缺少糖值的商品。分面标出有效数与类别总数。
- 碳气泡按照类别、AGRIBALYSE 食品代码、代理代码、名称与碳估算值分组。87 个参考项组合对应 594 款商品。气泡面积与共享商品数成正比；各类别使用相同的面积映射。果汁碳值仍为 kg CO₂e/kg 食品。
- 联合热图使用完整类别的中位价作为颜色基准，空单元格表示没有商品。非空单元格共 72 个，合计 583 款。
- 敏感性线段从 `rho_main_same_goods` 连至 `rho_variant`；`rho_main_full` 保留在明细表中。样本变化与价格口径变化保持区分。
- 年际变化仅使用两年都有有效代表价格的 193 款商品；不混用只要两年存在报价就计数的字段。

## 网站交互与数据

六个分析方向共用类别选择器，默认全部四类，支持中英切换。覆盖热图点选显示缺失商品，联合热图点选显示对应单元格商品。年际明细支持搜索、排序、分页。CSV 导出使用当前类别下的完整图表数据，年际明细导出包含全部搜索结果。

`website/scripts/export-dashboard.R` 导出修正后的商品、已执行结果表和箱线统计；`website/scripts/check-dashboard.mjs` 核对来源哈希，并独立验证图表中的统计与分组。前端采用 React、TypeScript 与 SVG，沿用现有 Vite 静态部署。R 分析和 Shiny 课程应用保留。

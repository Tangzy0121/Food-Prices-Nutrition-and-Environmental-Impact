 ## 结论核对

早餐谷物与黑巧克力的价格—环境分数相关分别为 0.307、0.243，饼干与果汁分别为 0.030、0.035。各类别最高代表价格商品的环境等级依次是 C、D、B、D，均未达该类样本中的最佳环境等级。

营养方面，黑巧克力随价格提高呈糖更少、饱和脂肪更多的权衡，不能将饱和脂肪增加写成营养改善。现有表是描述性相关，没有据此新增“显著”结论。企业投入、认证溢价的因果效果与柠檬市场机制没有直接测量，保留为研究背景或待检验解释。第三条结论按用户要求留待审阅联合图后确定。

## 数据范围

法国 2024–2025 年 EUR 报价连接到 2026-11-02 获取的商品资料。固体按 EUR/kg 与 g/100 g，果汁按 EUR/L 与 g/100 ml；合图保留这些单位，不假设果汁密度。跨类别位置用于观察分布，具体采购比较宜筛选同一类别。碳估算统一为 kg CO₂e/kg 食品，属于食品参考项模型值。当前网页导出包含碳估算与环境综合评分，没有分别可用的水耗、土地占用指标。

## 重建与验证

在 `website/` 运行 `npm ci`，再运行 `npm run build:standalone`，生成 `outputs/dashboard/2026-11-18-food-signal.html`。常规网站构建仍为 `npm run build`。

浏览器回归：`npm run check:consumer -- http://127.0.0.1:5173/#dashboard`；也支持直接传入独立 HTML 的 file URL。Chrome 路径由 `CHROME_PATH` 配置，默认使用本机 Windows Chrome。

改版前同一检查失败：实际六页，期望三页。改版后已通过真实浏览器的多选、空选择、统一坐标、商品详情、双语、390px 手机宽度与来源页检查。`npm run build` 同时通过既有 R 数据一致性、56 步处理流程和 TypeScript 检查；独立 HTML 也已用 file URL 通过交互检查。

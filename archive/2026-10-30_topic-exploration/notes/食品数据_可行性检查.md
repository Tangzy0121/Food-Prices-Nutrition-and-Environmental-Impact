# 食品价格与评分数据：首轮可行性检查

检查日期：2026-10-30。目标是评估法国、欧元、2024—2025 年价格是否可与食品类别、商品规格、营养评分和环境评分连接；不是检验价格与评分的关系。

## 数据与范围

- Open Prices 官方价格快照：`data/screening/open_prices_2026-10-30.parquet`，来源 https://huggingface.co/datasets/openfoodfacts/open-prices ，下载快照共 337,631 条；SHA-256 `32aa1ca9de2663d4b455fdc70421ead1c7d7a1d01a4b2b76bfffabbabab91725`。快照和实时 API 同步时点不同，因此数量可能不一致。
- 筛选地点国家代码 FR、币种 EUR、日期 2024/2025、类型 PRODUCT、非空条码、价格大于 0：83,141 条价格记录，44,789 个不同商品条码。价格观测 2024/2025 不代表评分采集时间。
- 商品信息通过 Open Prices API 返回的当前 product 对象读取，随机种子 20261030，从 44,789 个条码不放回抽 200 个。请求均返回至少一条价格记录，其中 199 个含商品对象、1 个商品对象为空。抽样原始响应为 `data/screening/food_product_sample_2026-10-30.json`；脚本为 `analysis/screen_food_sample.py`。API 商品内容是动态的，重新请求的分数可能变化。

## 抽样结果

以下以 200 个抽中条码为分母，空商品对象记为未匹配；各项并非互斥。营养等级接受 a—e；环境等级接受 a-plus 和 a—e；规格要求数值大于 0 且单位属于 g/kg/ml/l/cl；类别仅要求至少一个类别标签，不代表已完成食品类别有效性核验。

| 条件 | 商品数（共 200） |
| --- | ---: |
| 有商品对象 | 199 |
| 营养等级 a—e | 130 |
| 环境等级 a-plus、a—e | 115 |
| 两种等级同时存在 | 99 |
| 可识别质量或体积规格 | 147 |
| 有至少一个类别标签 | 163 |
| 两种等级、可识别规格、类别标签同时存在 | 93 |

93/200 = 46.5% 是这次简单随机样本中的粗略字段共现率，不代表最终可分析率，也不保证食品分类正确、售价单位与规格相符、评分时间与价格一致。抽样来自有记录的条码，不是法国市场的代表性商品样本。对候选 93 商品标签做粗略计数：零食类标签 20、乳制品 14、饼干和蛋糕 10；标签层级及交叉重叠，既非互斥分组也非最终样本量。必须进一步统一类别和筛选对比范围。

## 关键判断和下一步

数据有值得继续探索的规模，但当前只确认字段共现，不能声称全部可用。下一步优先检验价格是每件还是每公斤/升、规格是否为净含量（尤其多件装）、折扣和重复、类别有效性、评分方法版本及其历史时间。逐类统计有效独立条码和记录，区分 g 与 ml。当前评分匹配历史价格可能带来时间错配，必须明确标注，或者改用更近价格/有历史版本的商品资料。法国社群贡献的观察数据可能集中在某些门店、贡献者和商品上，不应外推全国。

本次只检查覆盖，没有检验价格与评分的统计关系。营养和环境评分都是方法定义的代理指标，不可等同完整健康效果或个体商品的实测环境影响。

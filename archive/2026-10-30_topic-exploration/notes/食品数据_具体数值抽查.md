# 商品营养与环境具体数值：接口抽查

检查日期：2026-10-30。

## 数据来源与结果

通过商品条码读取 Open Food Facts 产品 API `nutriments` 和 `ecoscore_data.agribalyse`；官网营养字段说明：https://openfoodfacts.github.io/documentation/docs/Product-Opener/schemas/schemas/product_nutrition/ 。代码：`analysis/screen_food_numeric.py`，截取结果：`data/screening/food_numeric_sample_2026-10-30.json`。从前一轮 200 个随机条码的前 30 个抽查；30 个请求中 13 成功返回商品，8 返回 HTTP 429、5 返回 HTTP 404、4 返回 SSL 错误。接口失败不等于字段缺失。13 个成功响应均含 energy-kcal、sugars、fat、saturated-fat、proteins 的 _100g 数值；7 有 fiber，12 有 salt；9 有 `ecoscore_data.agribalyse.co2_total`。9 个均有 sugars。仅 13 个成功，不足以估计总体覆盖率。30 个接口请求不是为严格估计而完成的有效样本。

## 示例

条码 3483190093354，Rillette de poulet；法国价格快照含 2024-03-15 价格 2.170 EUR。当前商品资料提供 per 100 g: 262 kcal、糖 0.5 g、脂肪 20 g、饱和脂肪 5.7 g、蛋白质 20 g、盐 1.4 g。环境对象关联 AGRIBALYSE 3.2 食品代码 8040（Rillettes, poultry），co2_total 为 5.68；其参考生命周期气候影响通常以 kg CO2e/kg 食物表示（应在正式分析前对照版本原始文档和功能单位）。这是食品类别模型值，不是商品独立供应链实测；产品资料和价格日期并不一致。

## 重要限制

- `_100g` 对固体一般每 100 克、液体每 100 毫升；营养值中某些字段可能根据来源输入或算法推导，不等于全部都是实验室实测；估算营养 `nutriments_estimated` 与 `nutriments` 应区别。
- `co2_total` 来源于匹配的 AGRIBALYSE 食品类别；同一类别多款商品可能具有相同环境数值。可能存在不精确匹配，例如抽查中 Lindor Lait 匹配到 `Candies, all types`；须逐类检查。类别模型不可反映每款商品的品牌、工厂、供应链差异，也可能在同类比较中缺乏变异。
- 2024—2025 价格与当前营养、类别、环境模型版本存在时点错配，历史配方和价格同一时刻并未核验。
- 需尊重 API 限流：HTTP 429 是速率限制，不应频繁重试；大规模连接宜考虑官方产品批量数据或在允许限速下提取。5 个 404 以及 4 个网络异常同样需要单独检查，不可作缺失值。
- 研究结论目前没有计算；下一步核查价格单位、食品类别映射质量、批量数据以及同组碳排放值变异。
